# 音響くん

キーボードを押すと音が鳴る、ステージ用の音出しアプリです。

## 使う

ブラウザで開く: https://okahaya.github.io/StageSounds/

Windows アプリ版をダウンロード: https://github.com/okahaya/StageSounds/releases/latest
（`Onkyokun-Windows.exe` をダウンロードして、ダブルクリック。インストール不要）

Mac はブラウザ版を使ってください。

## 使い方

1. 右上の **Edit** を押す
2. 鳴らしたいキーのタイルに音源ファイル（mp3 / wav / m4a など）をドラッグする
   タイルをクリックすると、名前・フェードイン/アウト・ループを設定できます
3. **Done** を押して編集を終える
4. キーを押すと再生

| 操作 | キー |
|---|---|
| 再生 / 停止 | 割り当てたキー（同じキーをもう一度押すと停止） |
| 一時停止 / 再開 | Space |
| 全部止める | Esc（画面下の赤いバーでも可） |

別のキーを押すと、前の音は止まって新しい音に切り替わります。

## 団体ごとの設定を共有する

右上の **⋯** → **Export** で、音源ごと `.stagepack` ファイルに書き出せます。
受け取った人は **⋯** → **Import**（または画面にドラッグ）で読み込めます。
